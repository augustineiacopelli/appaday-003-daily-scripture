# 003 · Daily Scripture

A daily scripture companion that surfaces a random Bible verse from 50 passages spanning both Testaments. Tap for a new verse, see the reference and testament label, with a contemplative illuminated-manuscript design.

**Category:** Utility Tool (U)  
**Stack:** HTML, CSS, JavaScript  
**Published:** 2026-05-09  
**Live URL:** [username].github.io/appaday/appaday-003-daily-scripture

---

## What It Does

Displays a random Bible verse on load. Tap **New Verse** to fade to another passage. Each verse shows the full text, the scripture reference, and whether it comes from the Old or New Testament.

## Features

- 50 curated verses across both Testaments
- Smooth fade transition between verses
- Testament label (Old / New) on every verse
- Illuminated manuscript aesthetic — EB Garamond serif, gold accents, corner ornaments, parchment noise texture
- Consistent AppADay header with app number and portfolio link
- Mobile-friendly at 375px viewport

## Usage

Open `index.html` in any browser. No internet connection required after fonts load. No API key, no dependencies, no build step.
